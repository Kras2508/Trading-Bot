========================================
HUONG DAN SUA LOI PYTHON NHANH
========================================

VAN DE:
Python khong chay duoc vi tim sai thu muc Lib

GIAI PHAP NHANH NHAT:
----------------------
1. Chay: DI_CHUYEN_DU_AN.bat
   => Se copy du an sang C:\TradingBot

2. Mo terminal o C:\TradingBot

3. Chay:
   python -m pip install -r requirements.txt --user
   python run.py

HOAC CAI LAI PYTHON:
--------------------
1. Go Python hien tai
2. Tai Python tu python.org
3. Khi cai, CHON "Add Python to PATH"
4. Cai xong, chay lai:
   python -m pip install -r requirements.txt
   python run.py

HOAC DUNG PYTHON TU MICROSOFT STORE:
-------------------------------------
1. Mo Microsoft Store
2. Tim "Python 3.11"
3. Cai dat
4. Chay:
   python -m pip install -r requirements.txt
   python run.py
